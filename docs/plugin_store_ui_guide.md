# 插件商店界面使用指南

## 访问地址

访问插件商店界面：
```
http://localhost:9292/plugin-store/store
```

## 界面功能

### 1. AI智能推荐

- **位置**：页面顶部
- **功能**：输入需求描述，AI会自动推荐合适的插件
- **使用方式**：
  1. 在输入框中描述您的需求，例如："我需要保存草稿的功能"
  2. 点击"推荐插件"按钮
  3. AI会返回推荐插件列表，包括：
     - **推荐安装**：核心功能必需的插件
     - **可选插件**：增强功能的插件
     - **推荐理由**：说明为什么推荐这些插件

### 2. 搜索功能

- **位置**：搜索栏
- **功能**：按关键词搜索插件
- **使用方式**：
  1. 在搜索框输入关键词（插件名称、描述、标签等）
  2. 按回车或点击"搜索"按钮
  3. 显示匹配的插件列表

### 3. 分类筛选

- **位置**：筛选标签栏
- **功能**：按分类筛选插件
- **可用分类**：
  - **全部**：显示所有插件
  - **保存策略**：保存相关的策略插件
  - **提交策略**：提交相关的策略插件
  - **权限策略**：权限控制相关的插件
  - **字段处理**：字段处理相关的插件
  - **已安装**：只显示已安装的插件

### 4. 插件卡片

每个插件卡片显示：
- **插件名称**：插件的名称
- **描述**：插件的功能描述
- **作者**：插件作者
- **版本**：插件版本号
- **标签**：插件的标签（用于分类和搜索）
- **状态标识**：
  - **内置**：系统内置插件（绿色标签）
  - **已安装**：已安装的插件（蓝色标签）
- **操作按钮**：
  - **安装**：安装插件（未安装时显示）
  - **卸载**：卸载插件（已安装时显示）
  - **详情**：查看插件详细信息

### 5. 插件详情

点击插件卡片或"详情"按钮，会弹出详情窗口，显示：
- 完整的插件描述
- 使用示例代码
- 配置说明
- 安装/卸载按钮

### 6. 安装/卸载插件

#### 安装插件
1. 点击插件卡片上的"安装"按钮
2. 确认安装
3. 系统自动：
   - 从MongoDB读取插件代码（商城插件）
   - 写入文件系统
   - 更新配置文件
   - 注册到策略系统

#### 卸载插件
1. 点击插件卡片上的"卸载"按钮
2. 确认卸载
3. 系统自动：
   - 删除插件文件
   - 从配置文件中移除
   - 取消注册

## 界面特性

### 响应式设计
- 插件卡片采用网格布局
- 自适应不同屏幕尺寸
- 类似VSCode插件商店的视觉风格

### 实时更新
- 安装/卸载后自动刷新列表
- 状态标识实时更新
- 无需手动刷新页面

### 交互体验
- 卡片悬停效果
- 加载状态提示
- 操作确认对话框
- 成功/失败提示

## 使用示例

### 示例1：通过AI推荐安装插件

1. 在AI推荐面板输入："我需要一个保存草稿的功能"
2. 点击"推荐插件"
3. AI返回推荐：`strategy-save-draft`（草稿保存策略）
4. 点击推荐插件旁边的"安装"按钮
5. 确认安装
6. 安装成功后，插件状态变为"已安装"

### 示例2：搜索并安装插件

1. 在搜索框输入："权限"
2. 显示所有权限相关的插件
3. 找到"默认权限策略"插件
4. 点击"详情"查看完整信息
5. 在详情窗口中点击"安装插件"
6. 确认安装

### 示例3：查看已安装的插件

1. 点击筛选标签中的"已安装"
2. 只显示已安装的插件列表
3. 可以查看已安装插件的详情
4. 可以卸载不需要的插件

## 技术实现

### 前端技术
- **Layui**：UI框架和组件
- **jQuery**：DOM操作和AJAX请求
- **原生JavaScript**：业务逻辑

### API端点
- `GET /api/plugin-store/list` - 获取插件列表
- `GET /api/plugin-store/search` - 搜索插件
- `GET /api/plugin-store/:id` - 获取插件详情
- `POST /api/plugin-store/install` - 安装插件
- `POST /api/plugin-store/uninstall` - 卸载插件
- `GET /api/plugin-store/installed` - 获取已安装插件
- `POST /api/plugin-store/recommend` - AI推荐插件

### 数据流
```
用户操作
  ↓
前端AJAX请求
  ↓
API路由 (/api/plugin-store/*)
  ↓
PluginStore服务
  ↓
MongoDB / 文件系统
  ↓
返回结果
  ↓
前端更新界面
```

## 注意事项

1. **权限控制**：当前实现未包含权限控制，生产环境需要添加
2. **错误处理**：所有操作都有错误提示
3. **内置插件**：内置插件不能卸载
4. **安装冲突**：如果插件已安装，会提示错误
